# Contributing to SealedCash circuits

Thank you for helping improve the SealedCash privacy circuit tooling.

1. Open an issue describing the problem or proposed change.
2. Keep circuit semantics, public-input order, and witness shapes explicit in code and tests.
3. Add or update a synthetic test vector for behavior changes. Never commit private keys, credentials, deployment details, or production artifacts.
4. Run `pnpm test`, `pnpm build`, and the proof/verification commands relevant to your change.
5. Submit a focused pull request with a concise security and compatibility impact summary.

By contributing, you agree that your work is provided under the MIT license.
